Пакетна автоматизація iRedAdmin — прямо з робочого стола.

MailGrit — крос-платформний десктоп-додаток для пакетного створення, редагування та видалення облікових записів користувачів пошти на серверах iRedAdmin — навіть за FortiWeb / WAF — через вбудований браузер, який виконує легітимний fetch у справжній сесії. Без інструментарію Node/JS: нативний WebView2/wry через Dioxus 0.7.

01 / Можливості

Усе для керування поштовими акаунтами у масштабі.

Нативна панель поверх справжньої сесії iRedAdmin — без крихкого відтворення куків і без окремого HTTP-клієнта, що ламається за WAF.

Пакетні операції на основі CSV

Керуйте масовим створенням / редагуванням / видаленням із CSV. BOM видаляється автоматично, заголовки зіставляються гнучко (нечутливі до регістру), а жорсткі обмеження на кількість рядків і довжину захищають від випадкових великих вхідних даних.

Ланцюговий журнал аудиту з виявленням втручання

Кожна операція додається до ланцюга, стійкого до втручання (HMAC-SHA256), тож будь-яке видалення, переставляння чи зміну минулого запису буде виявлено під час перевірки. Експорти та резервні копії шифруються в спокої потоковим AEAD (XChaCha20-Poly1305).

Захист ключем головного пароля

Виводить ключ журналу аудиту та ключ експорту через Argon2id (KDF, стійкий до атак по пам'яті). Пароль ніколи не зберігається: втративши його, ви не зможете перевірити журнал аудиту та розблокувати зашифровані експорти.

Працює за FortiWeb / WAF

Запити виконуються як fetch у тому самому вебв'ю, що утримує легітимну сесію, тож серверну автентифікацію, яку тримає проксі, не потрібно відтворювати — без вгадування куків.

9 мов, скомпільовано всередину

Англійська, німецька, французька, іспанська, італійська, португальська, нідерландська, польська та українська. Переклади вбудовуються в бінарник; ваш вибір зберігається в config.toml.

Безрамковий інтерфейс з темами

Власна дизайн-система на CSS-токенах: користувацький тайтлбар, темна та світла теми з перемикачем, симетрична сітка карток, модальне підтвердження для руйнівних операцій та індикатори прогресу.

02 / Модель безпеки

Безпека за замовчуванням, контрольована під час компіляції.

Безпека — це політика всього воркспейсу, а не «найкраще зусилля»: unsafe_code = "forbid", суворий clippy та перевірки ланцюга постачання виконуються на кожній підтримуваній платформі у CI.

Політика, що не може «попливти»

  • unsafe_code = "forbid" у всьому воркспейсі — жодного unsafe в жодному крейті додатку.
  • Групи clippy correctness, suspicious, complexity, perf, pedantic, nursery та cargo — усі deny.
  • panic, unwrap_used, expect_used, indexing_slicing, arithmetic_side_effects — усі deny.
  • Ланцюг постачання: cargo-deny (advisories, bans, licenses, sources) плюс cargo-audit.
  • Цілісність журналу аудиту: хеш-ланцюг HMAC-SHA256. Зашифровані експорти та резервні копії: потоковий AEAD XChaCha20-Poly1305.
  • Головний пароль: Argon2id — KDF, стійкий до атак по пам'яті; ніколи не зберігається і не логується.
Cargo.toml
# Без винятків: wry 0.53 повертає HttpOnly cookies нативно.
# Кожен крейт додатку перевіряється за цією політикою.
[workspace.lints.rust]
unsafe_code = "forbid"

[workspace.lints.clippy]
correctness      = { level = "deny", priority = -1 }
suspicious       = { level = "deny", priority = -1 }
pedantic         = { level = "deny", priority = -1 }
unwrap_used      = "deny"
indexing_slicing = "deny"
arithmetic_side_effects = "deny"
panic            = "deny"

04 / Швидкий старт

Одна команда до release-збірки.

MailGrit — це воркспейс Cargo; зберіть десктоп-додаток для своєї платформи й запускайте його безпосередньо.

bash
# Потребує Rust 1.97.1 (закріплений через rust-toolchain.toml, edition 2024)
$ cargo build --release -p mailgrit-app-desktop

# Windows
> .\target\release\mailgrit-app-desktop.exe

# Linux / macOS
$ ./target/release/mailgrit-app-desktop

Під час першого запуску поряд із бінарником створюється тека mailgrit-data/, де зберігаються усі файли додатку. Вкажіть URL вашого iRedAdmin, увійдіть один раз у вбудованому браузері — і панель операцій відкриється автоматично.

05 / Архітектура

П'ять крейтів, кожен можна тестувати окремо.

Воркспейс Cargo, де шари домену, парсингу, сховища, безпеки та інтерфейсу розділені — cargo test -p <crate> запускає кожен окремо.

Структура воркспейсу

  • core-domain — доменні типи (Newtype/Typestate), помилки, константи обмежень, політика паролів.
  • core-csv — парсинг та валідація CSV із видаленням BOM і жорсткими обмеженнями пам'яті.
  • core-storage — локальне сховище SQLite: журнал операцій і ланцюговий журнал аудиту.
  • core-security — криптографія у спокої: потоковий AEAD, HMAC-хеш-ланцюг, Argon2id KDF.
  • app-desktop — десктоп-додаток Dioxus 0.7: вікно входу, обробка куків, нативна RSX-панель.

06 / FAQ

Часті запитання.

Що таке MailGrit, як він працює та як залишається безпечним.

Що таке MailGrit?
MailGrit — це безкоштовний крос-платформний десктоп-додаток із відкритим кодом, написаний на Rust, який виконує пакетне створення, редагування та видалення поштових акаунтів користувачів на поштових серверах iRedAdmin. Це інструмент адміністрування, а не поштовий клієнт для читання листів.
Які операційні системи підтримує MailGrit?
MailGrit працює на Windows, Linux (x86_64) та macOS на Apple Silicon (aarch64). Додаток створено на базі десктоп-фреймворку Dioxus і використовує системний WebView, тому немає потреби у Node чи JavaScript-інструментарії.
Чи працює MailGrit за FortiWeb або WAF?
Так. Пакетні операції виконуються як JavaScript fetch POST справжньої HTML-форми створення/редагування iRedAdmin (із CSRF-токеном) усередині того ж вбудованого webview, що тримає легітимну сесію. Оскільки запит походить із автентифікованого браузерного сеансу, він працює навіть тоді, коли сервер знаходиться за FortiWeb або іншим веб-фаєрволом (WAF).
Як MailGrit автентифікується на iRedAdmin?
Ви входите через вбудований браузер, використовуючи свої справжні облікові дані iRedAdmin. Додаток визначає успішний вхід орієнтованим на дані способом — за переходом webview входу на /dashboard, а не вгадуванням імен cookie. Потім він виконує операції як fetch у межах того ж автентифікованого webview.
Чи безпечний MailGrit? Як захищений журнал аудиту?
Кожна операція додається до ланцюга, стійкого до втручання (HMAC-SHA256), що захищає цілісність: будь-яке видалення, переставляння чи зміну минулого запису буде виявлено під час перевірки (verify). Зашифровані експорти та резервні копії захищені у спокої потоковим автентифікованим шифруванням (XChaCha20-Poly1305), ключі для якого виводяться з майстер-пароля через Argon2id; майстер-пароль ніколи не зберігається. Робочий простір застосовує unsafe_code = "forbid", тож у крейтах додатку немає unsafe-коду.
Чи безкоштовний MailGrit і яка у нього ліцензія?
MailGrit безкоштовний і має відкритий код, подвійно ліцензований за ліцензією MIT або Apache License 2.0 на ваш вибір. Вихідний код і готові бінарні файли доступні на GitHub. iRedAdmin є торговою маркою відповідних власників; MailGrit незалежний і не пов'язаний із iRedAdmin та не схвалений ним.
